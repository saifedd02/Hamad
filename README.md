# Hair & Cut

Statische Website für einen Barbershop in Dortmund. Die Seite stellt Leistungen, Preise, Team und Kontaktmöglichkeiten vor. Eine Terminanfrage wird als vorbereitete WhatsApp-Nachricht geöffnet.

## Technik und Aufbau

HTML, CSS und JavaScript ohne Build-Werkzeug. `index.html` enthält die Seite, `style.css` die Gestaltung und `script.js` die Interaktionen. Bilder und Videos liegen in eigenen Verzeichnissen.

## Lokal ansehen

```bash
python3 -m http.server 8000
```

Anschließend `http://localhost:8000` öffnen. Der Aufruf dient nur der lokalen Vorschau. Das Repository enthält keinen Buchungsserver und keine zentrale Terminverwaltung.

## Projektstand

Website-Projekt mit Schwerpunkt auf responsiver Darstellung und Kontaktaufnahme.
